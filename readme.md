# Google Authenticator secret extractor

[中文文档](README-zh_CN.md)

> **Note:** This project and I are in no way affiliated with Google.

This lets you decode the URI generated by Google Authenticator, and re-generate QR codes for importing into other authenticator apps.

![Example](example.png)


## Features

- Decode Google Authenticator export QR codes / URIs
- Output as JSON or terminal QR codes for re-import
- Drag & drop QR code images directly into the terminal
- Edit account name / issuer before generating QR codes
- Import multiple QR codes with automatic deduplication
- Re-generate QR codes from previously exported JSON files
- Supports TOTP / HOTP, SHA1 / SHA256 / SHA512, 6 / 7 / 8 digit codes


## Guide

**Prerequisites:**
* Your phone with Google Authenticator
* A camera
* [Node.js installed](https://nodejs.org/en/download/)
* (Optional) A QR scanner app if not using drag & drop
    * Android: [ZXing](https://play.google.com/store/apps/details?id=com.google.zxing.client.android)
    * Mac/Win/Linux: [ZBar](https://github.com/mchehab/zbar) (See [issue 22](https://github.com/krissrex/google-authenticator-exporter/issues/22) for usage)


### Getting the export QR codes

1. Open the Google Authenticator app.
2. Click Settings (three dots, top right), and *Transfer accounts*.
3. Select *Export accounts*.
4. Authenticate, if prompted.
5. Select the accounts you want to export (default is *all*).
6. Click *Next*, and capture a picture of the QR code.
    * **Note:** Screenshots are disabled by the app.
    Use your laptop webcam, a digital camera or another phone.
7. Click *Next*, and repeat step 6 for all QR codes shown (if you have many accounts).


### Setup

```sh
git clone https://github.com/krissrex/google-authenticator-exporter.git
cd google-authenticator-exporter
npm install
```


### Usage: Decode from QR image (drag & drop)

The easiest way — drag the QR code image directly into the terminal:

```sh
npm start
```

```
URI or image path: /path/to/qr-photo.jpg      ← drag image here
  +10 account(s), total: 10

URI or image path (Enter to finish): /path/to/qr2.jpg   ← add more, or Enter to finish
  +5 account(s), total: 15

URI or image path (Enter to finish):           ← press Enter

15 account(s) ready.

Output: 1 JSON  2 QR Code (for re-import)
>
```

- Choose **1** to output JSON (optionally save to file)
- Choose **2** to display terminal QR codes for each account, which you can scan to import into another app

Supports PNG, JPEG, WebP and other common image formats. Duplicate accounts across multiple images are automatically removed.


### Usage: Decode from URI

If you already have the decoded URI text (e.g. via a QR scanner app):

```sh
npm start
```

Paste the `otpauth-migration://offline?data=...` URI when prompted.


### Usage: Re-generate QR codes from JSON

If you previously exported to JSON and want to generate QR codes again:

```sh
node src/index.js --from-json accounts.json
```

This enters QR code mode directly, letting you scan each account and optionally edit name/issuer.


### QR code mode: editing accounts

In QR code mode, each account is displayed with its info and a scannable QR code. You can edit the name and issuer before scanning:

```
  Account 1/3
  Name:      old-account-name
  Issuer:    OldService
  Algorithm: SHA1
  Digits:    6
  Type:      TOTP

  ▄▄▄▄▄▄▄ ▄ ▄▄▄▄▄▄▄
  █ QR CODE █
  ▀▀▀▀▀▀▀ ▀ ▀▀▀▀▀▀▀

  New name (Enter to keep): my-new-name        ← type to rename, or Enter to skip
  New issuer (Enter to keep): NewService

  Account 1/3                                  ← updated info + QR shown immediately
  Name:      my-new-name
  Issuer:    NewService
  ...

==================================================

  Account 2/3
  ...
```


## Use a docker image

**Prerequisites:**

Build the docker image locally:
```sh
docker build . --tag google-authenticator-exporter:0.0.1
```

**Decode an obtained QR code URI:**
1. Run the docker container locally:
```sh
docker run -it --rm google-authenticator-exporter:0.0.1
```
2. Enter the URI when prompted
3. Since you haven't mounted a volume, you cannot save the output using the above command, so leave the next questions empty (hit Enter).
4. The output to JSON will be printed out to terminal.
